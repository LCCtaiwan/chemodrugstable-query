# ChemoDrugStable 查詢頁

化療調配核對查詢，資料版本 1150806，共 84 個品項。

- 本頁為核對輔助，不取代仿單、院內調配規範與雙人核對。
- 正式發布內容須依院內流程核對與簽核。
- 網頁為單一靜態 HTML，不會上傳使用者輸入內容。

## 健保給付與電子仿單查詢

- 線上頁面：<https://lcctaiwan.github.io/chemodrugstable-query/nhi/>
- 每天（台灣時間）由 GitHub Actions 檢查健保署與 TFDA 官方資料；來源通過檢查後才重新建置。
- 給付規定以健保署官方 Word 修改日期、PDF 內文日期及線上既有版本自動交叉確認；PDF 完整性、頁數、檔案大小與章節覆蓋率也會一併檢查。
- 若官方 Word 已更新但 PDF 尚未同步，排程會保留既有線上版並等待下次檢查，不需要人工更換版本日期。
- 查詢結果保留官方規定原文與連結，不代替個案給付判定。
- 條文只依章節與條款層級重新排版，不使用關鍵字彩色標記。
- 電子仿單依 TFDA 許可證字號產生官方連結；不抓取或改寫仿單臨床文字，同一學名的不同廠牌分開列出。

官方直連設定在 `tools/nhi/rules_source.json`，建置紀錄會輸出為 `/nhi/data_version.json`。只有健保署更換附件網址或官方檔案彼此無法對應時，才需要人工處理。
