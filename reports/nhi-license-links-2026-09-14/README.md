# 健保碼與 TFDA 許可證串接：第一輪實測

基準日：2026-09-14。範圍為全部健保藥品，未限縮化療藥。

|結果|健保碼數|
|---|---:|

|唯一對應至未註銷 TFDA 許可證|28,638（63.39%）|

分母採既有程式的日期判定，不代表所有品項仍上市或可供應。未對應不等於不存在許可證，也不代表沒有電子仿單。

## 方法與限制

1. 使用健保署 CSV 的「藥品代碼超連結」中 `licId`，不從健保碼或品名猜測。
2. 使用 TFDA 37 的「通關簽審文件編號」正規化成相同識別碼，例如 `DHY00104809200` → `01048092`，並核對中文許可證的六位流水號。這是依來源編碼結構進行的轉換，不是官方另行提供的交叉對照檔。
3. 通關號缺漏、不支援的格式（包括 S 前綴）、流水號不一致都不轉換。多筆候選或不在未註銷清單內不自動連結。未對應原因尚未逐筆人工查證。
4. 顯示 TFDA 37 原文「適應症」，與健保給付條文分開。仿單入口不等於已確認有全文。
5. 每次既有健保更新建置都重新串接；既有來源下載失敗不發布的機制沿用。

本次原始健保 CSV 224,811 列。來源雜湊與統計見 summary.json。

官方來源：
- [健保品項 CSV](https://info.nhi.gov.tw/api/iode0000s01/Dataset?rId=A21030000I-E41001-001)

## 重現

```sh
python tools/nhi/audit_license_links.py --csv /path/nhi.csv --tfda-licenses /path/tfda.zip --as-of 2026-09-14 --output /path/audit
python -m unittest discover -s tests -p 'test_nhi*.py'
```

稽核程式輸出 summary.json 與逐筆 links.csv。大型逐筆檔不納入 Git；可依官方檔案重建。
